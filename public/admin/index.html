🛡️ 组内专属内容与内部专区安全机制

当您将文章或文档设置为 🔒 仅组内可见 时，系统会自动受 Cloudflare Zero Trust (Access) 防护：
• 免密白名单：课题组成员访问内部页面时，系统会弹出验证码登录或微软 365 单点登录；
• 身份鉴权：只有持有 @yzu.edu.cn 或您指定的组内学生邮箱的成员才能阅读；
• 外部访客：将被阻断在外部，保障实验室周报、培养计划与未公开数据的绝对安全。

👥 内部白名单快速管理

您可以在 Cloudflare 控制台的 Access 策略 中直接指定允许访问的规则：

  • 规则 1（全校通用）：允许所有邮箱后缀为 @yzu.edu.cn 的师生登录；
  • 规则 2（指定成员）：单独添加 25 位研究生的 QQ/163 邮箱；
  • 规则 3（管理员）：绑定您的 Microsoft Entra ID 全局管理员账号。
